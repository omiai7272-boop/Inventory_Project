# Inventory Tracking Analysis 📦📊

An interactive **Inventory Tracking Analysis Dashboard** developed using **Power BI** to monitor and analyze inventory-related data through interactive visualizations and key performance indicators.

### 📌 Dashboard Highlights
- Inventory performance analysis
- Key inventory-related metrics and KPIs
- Interactive charts and visualizations
- Data analysis using different business dimensions
- Interactive filters and slicers
- Dashboard designed for easy monitoring and analysis

### 🛠️ Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization

### 🎯 Objective
The objective of this project is to transform inventory data into an interactive Power BI dashboard that provides a clear and visual way to analyze inventory information and support data-driven decision making.
